# Backend API reference

These pages describe the **Bookly REST API** implemented in `backend/src/`.

When the API server is running, OpenAPI docs are also available at **http://localhost:8000/docs** (Swagger UI) and **/redoc** — that is separate from this `backend/docs/` markdown folder.

All paths below are under the prefix `/api/v1`.

| Module | Document |

| Books | [books.md](books.md) |
| Reviews | [reviews.md](reviews.md) |

For authentication requirements and token usage, see [Authentication](../authentication.md) and [Error handling](../error-handling.md).
